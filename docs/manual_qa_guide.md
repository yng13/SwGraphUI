# SwGraphUI 手動品質監査ガイド (1.0 Release Gate)

1.0 リリースに向けた、「体感品質」と「アクセシビリティ」の最終確認手順です。

## 1. 大規模グラフの UI 追従性 (M35b)

このテストでは、多数の要素が表示されている状態での操作の「粘り」を確認します。

- **場所**: Example アプリを起動し、サイドバーから **Feature Overview > Integrated Stress Test** を選択。
- **確認手順**:
    1. **パン (ドラッグ)**: 背景を掴んでキャンバスを高速に振り回す。ノードがマウス位置に遅延なく吸い付くか確認。
    2. **ズーム (ピンチ/ホイール)**: 高速にズームイン・アウトを繰り返す。背景のグリッドが点滅せずに滑らかに遷移（LOD フェード）するか確認。
    3. **アニメーション**: エッジの流れるアニメーションが、ズームアウト時でもカクつかず一定速度に見えるか確認。

## 2. ズーム耐性とギズモ品質 (M36)

深くズームした際に、操作用 UI が壊れないことを確認します。

- **場所**: **Custom Showcase > Node Resizer** を選択。
- **確認手順**:
    1. **ディープズーム**: ズーム倍率を最大付近まで上げる。
    2. **枠線の視認性**: ノード選択枠やリサイズガイドの線が、消えたり巨大化したりせず、常に 1.0〜2.0pt 程度の「適度な太さ」を維持しているか確認。
    3. **ハンドルの操作性**: リサイズハンドル（白い丸）がズームで見失わないサイズを保っており、かつ正確に掴めるか確認。

## 3. アクセシビリティ検証 (M33b)

支援技術を用いたユーザーが最低限操作できることを確認します。

- **準備**: Xcode を開き、メニュー `Xcode > Open Developer Tool > Accessibility Inspector` を起動。
- **場所**: **Interaction Playground > Interaction** を選択。
- **確認手順**:
    1. **ノードの役割**: Inspector の「照準アイコン」でノードをクリック。
        - **Label**: ノードのテキスト（"Node 1" など）が表示されるか。
        - **Role**: `Button` または `Static Text` として識別されるか。
    2. **選択状態の通知**: アプリ上でノードを選択（クリック）する。Inspector の **Traits** に `Selected` が現れるか確認。
    3. **不要要素の除外**: 背景グリッドやアニメーション中のエッジをクリック。Inspector がそれらを無視し、キャンバス全体を「グラフキャンバス」として認識しているか確認。

---

> [!NOTE]
> 体感上のラグ（遅延）が著しい場合や、読み上げ内容が ID のみ（n-123など）になっている場合は、1.0 Gate 未達としてフィードバックしてください。
